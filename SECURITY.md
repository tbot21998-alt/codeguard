# Security Policy & Disclaimer

## Purpose & Acceptable Use
CodeGuard is an open-source, dual-use defensive security tool designed to protect developers and agentic workflows from unauthorized command execution, data exfiltration, and prompt injection. It operates as a local static analysis and safety verification gate.

CodeGuard adheres to GitHub's Acceptable Use Policy:
- **No Malicious Intent**: CodeGuard is exclusively defensive software. It contains no exploit payloads, no attack scripts, no malware samples, and no backdoors.
- **Fail-Closed Gate**: CodeGuard functions solely as an inspection proxy to intercept and block risky operations on developer workstations.
- **Dual-Use Compliance**: Security rules and signatures within CodeGuard exist strictly for pattern matching and preventing unsafe code execution in accordance with defensive security practices.

## Reporting a Vulnerability
If you discover a security vulnerability or bypass within CodeGuard, please disclose it responsibly. Do not open public issues for sensitive security vulnerabilities. Please report security concerns via private repository vulnerability reporting or email the maintainers directly.
